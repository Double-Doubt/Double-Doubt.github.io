1950s · 前史

情欲片的温床：新东宝与"肉体女优"的诞生

粉红电影尚未得名，但性已登上日本银幕。旧大制片厂体系边缘的新东宝等公司，以海女、温泉、怪诞奇观片试探审查边界，为日后的类型诞生积累题材、演员与低成本制片模式。

产业与语境

  • 战后审查松动，海女（裸潜）与温泉风俗片盛行
  • 大藏贡主持的新东宝大量拍摄情欲喜剧
  • 三原叶子、万里昌代、根岸明美等"肉体女优"出现

代表人物 / 影片

  • 石井辉男、中川信夫、志村敏夫
  • 《珍珠女王的复仇》（1956）等奇观片
  • 怪诞、恐怖与情欲杂糅的新东宝风格
铺垫：审查尺度、裸露奇观与低成本制片在此成形。

1962–1969 · 诞生与独立期

"粉色电影"（eroduction）破土而出

1962 年小林悟《肉体市场》成为第一部粉红电影；"pink film"一词 1963 年由记者村井实创造。国映、大藏映画（OP Eiga）等独立公司建立起低成本、高产量、专门院线放映的生产模式。

产业与事件

  • 国映（1957）、大藏映画、新东宝映画相继立足
  • 武智铁二《白日梦》《黑雪》引发猥亵审判
  • 安保斗争与学运高涨，性表达与政治激进合流

代表人物 / 影片

  • 小林悟、本木庄二郎、关孝二、向井宽、渡边护
  • 《肉体市场》《肉体自由贸易》《情欲的谷间》
  • 向井宽《情事编年史》《蓝色电影女人》
转折：类型获命名、生产与院线体系成型；审查审判确立"打码"边界。
对应 第 1、2、4、5、6 章（类型定位、审查史、诞生、先驱、极左翼）

1965–1972 · 前卫与革命

浮出地下：若松制作与足立正生

若松孝二把色情片当作政治武器，与编剧足立正生、大和屋竺等人将性、暴力、前卫影像与革命政治熔为一炉；若松 Pro 成为独立电影与地下文化的据点。

若松孝二的创作

  • 《墙中秘事》《胎儿密猎时刻》
  • 《被侵犯的天使》《永远的处女》
  • 《性贼》《天使的恍惚》

足立正生与政治走向

  • 《堕胎》《避孕革命》《性地带》
  • 《女高中生游击队》《喷涌的祈祷》
  • 《赤军／PFLP：世界战争宣言》（1971）
转折：粉红电影被赋予强烈作者性与批判锋芒，进入国际前卫视野；足立正生随后投身中东革命。

1971–1978 · 制片厂化与黄金期

日活"罗曼色情"（Roman Porno）的金色黎明

老牌制片厂日活在经营危机下转向成人路线，1971 年推出罗曼色情系列，以固定预算与片长、定期上映、专业制作，把粉红电影提升到大众市场与艺术水准兼具的高度。

产业与制作

  • 日活每部约 70–80 分钟、固定预算、约十天拍成
  • 宫下顺子、谷直美、白川和美等成为时代偶像
  • 与独立粉红系并存，并出现国际合拍

代表导演 / 影片

  • 神代辰巳、田中登、小沼胜、西村昭五郎、曾根中生
  • 神代《湿濡的欲望》《欢乐街》、田中《阿部定》
  • 小沼《供品夫人》《花与蛇》、大岛渚《感官世界》
转折：性电影首次被主流制片厂大规模接纳，作者导演在商业框架内拍出艺术杰作。
对应 第 9、10、11 章（罗曼色情开端、影片与明星、国际合拍）

1970s · 产业林立

"我好奇（粉）"：独立公司的繁荣与变动

在日活之外，国映、大藏映画、狮子制作、Million Film、Xces（新日本映像）、关东映配、东活等独立公司维持高产量生产，构成专门院线的片源网络，也孕育了更多风格各异的作者。

产业生态

  • 独立制片公司分工细密、彼此流通
  • 渡边护、小川钦也、西原仪一等高效拍片
  • 山本晋也、滨野佐知等坚持纪实与女性视角

特征与产出

  • 更快的拍摄周期、更低的预算
  • 与日活共享演员、剧组与发行渠道
  • 粉红产业在七十年代达到产能高峰
转折：独立部门与制片厂并行，粉红电影形成完整的产业生态。

1980s · 过度的十年

暴力、虐待与录像机冲击

院线观众因家庭录像（AV）崛起而流失，粉红电影转向更极端的暴力、强奸、SM 题材以图生存；曾经风光的日活在 1988 年停止罗曼色情、宣告破产，标志旧制片厂时代终结。

危机与极端化

  • 录像机普及、AV 与录像带分流成人观众
  • 强奸、虐恋、酷刑等"硬"题材泛滥
  • 日活罗曼色情 1988 年停摆并破产

代表导演 / 影片

  • 渡边护的谷直美 SM 系列
  • 小沼胜《箱中女》等 SM 化作品
  • 独立部门继续支撑专门院线
转折：媒介变革（AV／录像机）与题材过度透支，令传统院线粉红片陷入衰退。

1990s · 复兴与"新粉红浪潮"

四人组：独立电影的复兴

在低谷中，佐藤寿保、佐野和宏、佐藤俊喜（Toshiki Sato）、濑濑敬久四位风格激进的导演被称作"粉红四天王"，把廉价粉红片变成实验与个人表达的阵地，吸引了大批年轻影迷与未来主流影人。

四天王（Four Devils）

  • 佐藤寿保：冰冷、抽象、SM 与暴力美学
  • 佐野和宏：粗粝、压抑、扭曲的身体叙事
  • 佐藤俊喜：多在"团地妻"框架中做实验
  • 濑濑敬久：后来主流化，作品最具野心

出道于此的未来主流影人

  • 黑泽清、周防正行早年以粉红片练手
  • 广木隆一、泷田洋二郎由此起步
  • 粉红片成为年轻导演的"电影学校"
转折：极端低成本反而成为艺术自由的保护壳，粉红片迎来口碑复兴。

1990s–2000s · 边缘的声音

女性导演与同性恋粉红电影

当男性主导的粉红产业被女性工作者参与，以及 gay／lesbian 粉红片发展出独立的小生态，类型内部开始出现异质的视角：女导演滨野佐知长期拍摄女性视角，"粉红七福神"中的女性议题与男同粉红片共同拓展了边界。

女性的介入

  • 滨野佐知：1970 年起拍片，《百合祭》《贪婪主妇》
  • 女编剧、女导演、女制片人逐步增加
  • 女性视角对身体与欲望的重新书写

同性恋粉红片

  • 男同粉红片（gay porno）形成独立小市场
  • 粉红七福神中容纳多元题材
  • 性少数题材在低成本框架内被表达
转折：粉红电影不再是单一男性凝视，边缘视角进入类型内部。

2000s · DVD 时代与终幕

"粉红七福神"：粉红电影的最后浪潮？

DVD 与互联网进一步瓦解影院模式，七位风格各异的年轻导演组成"粉红七福神"（今冈信治、上野俊哉、女池充、田尻裕司、镰田义孝、榎本敏郎、坂本礼），以创意为衰落的类型注入活力；粉红电影转为小众文化与电影节遗产。

粉红七福神（Seven Lucky Gods）

  • 今冈信治《等待彗星》《水底的温柔》
  • 女池充《花井幸子的璀璨人生》《Bitter Sweet》
  • 上野俊哉、田尻裕司、镰田义孝等

媒介与遗产

  • 录像带、DVD、网络取代专门院线
  • 海外电影节、DVD 发行与学术关注
  • 濑濑敬久等转主流，园子温延续其血脉
终幕：作为固定院线类型的粉红电影走向尾声，但作为"作者训练场"与亚文化遗产被重新发现。
